Binomial Coefficient Identities
Validates Symmetry, Pascal's Additive Rule, and the Row Sum Identity (2^n) for chosen (n, r).
Verification Results
1. Symmetry Identity: C(n, r) = C(n, n - r)
2. Pascal's Additive Identity: C(n, r) = C(n - 1, r - 1) + C(n - 1, r)
3. Row Sum Identity: Σ C(n, k) = 2^n
Pascal's Triangle Generator
Constructs triangle rows from preceding row additions. Verified against C(n, k). (Rows 0 to rows - 1)
Properties: First and last entries are always 1 because C(n, 0) = C(n, n) = 1. Every interior number is the exact sum of the two elements above it. Row 5 values: 1 5 10 10 5 1 with row sum 32 (= 2^5).

Symbolic Mathematics & SymPy Verification Reference
Formal mathematical relationships verified symbolically in the companion Python tool.

1. Closed-Form Recurrence via SymPy rsolve()

For the Fibonacci recurrence F(n) = F(n-1) + F(n-2), SymPy solves the characteristic equation r^2 - r - 1 = 0 to yield the exact closed form (Binet's Formula):

F(n) = [((1 + √5) / 2)^n - ((1 - √5) / 2)^n] / √5

2. Symbolic Binomial Simplification

SymPy's simplify(expand((a*x + b*y)**n) - my_expansion) == 0 guarantees exact algebraic equivalence without floating-point approximations.
